## 1. 软件方案

目前国内主流的三款软件各有优劣，建议采取 **“1个主力 + 1个备用”** 的双保险策略：

| **软件名称**                          | **优点**                        | **缺点**            | **建议**                 |
| --------------------------------- | ----------------------------- | ----------------- | ---------------------- |
| [ToDesk](https://www.todesk.com/) | 2026年评测中连接速度最快（约2秒），基础版文件传输快。 | 偶尔有免费版限速提示。       | **首选主力**，界面清爽，移动端适配好。  |
| [向日葵](https://sunlogin.oray.com/) | 国内节点最稳，硬件生态（开机插座）无敌。          | 免费版画质一般，偶尔有广告。    | **备用首选**，配合其硬件实现远程开关机。 |
| **TeamViewer**                    | 老牌稳定，跨国连接强。                   | 容易被误判为“商业用途”导致断连。 | 如果你在国外或老家网络极差时尝试。      |

## 2. 如何解决“电脑关机了”？

回老家半个月，最怕老家还没到，家里停了一次电或者系统自动更新重启后死机。

- **方案 A（最推荐）：智能插座 + BIOS 设置**
  - 买一个**开机插座**或智能插座（如米家）。
  - **关键设置：** 进入电脑 BIOS，找到 `Power Management`，将 `AC Recovery`（断电恢复）设置为 **On** 或 **Last State**。
  - **操作：** 如果电脑死机或断电，你可以远程关闭插座再开启，电脑检测到通电会自动开机。
- **方案 B：WOL（网络唤醒）** ： 没有公网ip，
  - 如果不想买硬件，需在 BIOS 和网卡设置中开启 `Wake on LAN`。但这需要你的路由器支持且有公网 IP 或配置内网穿透，技术门槛稍高。

开启 BIOS “来电自启”,这是配合插座的核心步骤。你可以现在先重启电脑进入 BIOS（通常是反复按 `Del` 或 `F2`）：
- 找到 **Power Management Setup**（电源管理设置）。
- 寻找名为 **Restore On AC Power Loss** 或 **AC Recovery** 的选项。
- 将其从 `Power Off` 改为 **`Power On`**（或 `Last State`）。
- **测试：** 设置好后进入系统，直接拔掉电脑电源线，等 10 秒钟再插回。如果电脑自动开机，说明设置成功。
## 3. 检查清单

为了确保这半个月不掉链子，请在出发前完成以下操作：

1. **设置无人值守密码：** 在远控软件中设置“固定安全密码”，确保不需要端坐电脑前点“允许”。
2. **关闭自动睡眠：** 在 Windows 设置中，将“电源和睡眠”里的“睡眠”改为 **“从不”**。
  1. 关闭睡眠： 进入 `设置` -> `系统` -> `电源和睡眠`，将“屏幕”和“睡眠”都设置为 **“从不”**。
  2. 硬盘不休眠： 进入 `控制面板` -> `电源选项` -> `更改计划设置` -> `更改高级电源设置`，找到“硬盘”，设置为 **“从不”**。
3. **关闭 Windows 自动更新：** 避免半夜自动重启导致远控服务未启动（可以使用特定小工具暂停更新 5 周）。
4. **设置软件开机自启：** 确保 ToDesk 或向日葵勾选了“随系统启动”。
5. **隐私保护：** 开启软件的**“隐私屏”**功能。这样你操作时，老家的屏幕是黑的，防止邻居或亲戚路过看到你的操作。
6. 电脑最好插**网线**而非 Wi-Fi，Wi-Fi 在长期挂机中掉线概率更高。

## 4.注意点
1. 智能插座 开机需要在主板完全放电之后启动才有效，需要等待30s左右，所以马上断电再开启插座电脑也不会重启
2. 向日葵和todesk账号有可能会在重启的时候没登陆，这样的情况下就会导致无法连接到远程电脑：所以我是两个同时登陆，这样两个同时掉线的机率比较小，每次远程就检查一下账号的状态
